# 基于真实数据驱动的 LAS 微晶玻璃晶相智能预测与目标晶相设计系统

这是一个面向安徽省 AI 大模型创新应用竞赛的可运行科研原型，采用 Streamlit 构建。系统使用 `data/data_merged.csv` 中的真实成分、热处理工艺和晶相标签，完成晶相预测、目标晶相候选设计、模型评估和样品记录。

## 当前功能

- 真实 LAS 数据自动加载与结构检查
- 29 个成分字段和 4 个热处理字段输入
- 13 类晶相组合多标签预测
- 成分基线模型与成分+热处理工艺模型对比
- 按独立成分组合分组留出的测试评估
- 目标晶相与热处理约束驱动的候选方案生成
- 晶相概率、分晶相 F1、特征重要性展示
- 样品预测结果保存到 SQLite
- 预测结果、候选方案和样品记录 CSV 导出
- 数据筛选、成分和检查、工艺完整性检查

## 项目定位

当前系统的科学任务是：

```text
真实成分 + 热处理工艺 -> 晶相组合预测
```

系统暂不宣称透光率、强度、热膨胀系数、晶粒尺寸预测，也没有把晶相标签伪装成这些性能指标。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开终端显示的本地地址即可。

## 发布为公网网页

项目已准备好用于 Streamlit Community Cloud。详细步骤见 [DEPLOY.md](DEPLOY.md)。
部署后会获得一个 `https://*.streamlit.app` 网址，其他人无需安装 Python 即可打开。

公开部署前，请确认 `data/data_merged.csv` 中的数据允许对外发布。`.gitignore` 已排除本地样品记录数据库和上传图片。

## 当前真实数据

`data/data_merged.csv` 共 751 条记录，包含：

- 29 个成分字段
- `T_nucleation`、`t1`、`T_crystal`、`t2` 四个热处理字段
- 13 个晶相标签字段
- 550 种独立成分组合

详细审计结果见 `data/data_audit_report.md`。原始数据文件保留不变。

## 模型评估

当前采用 ExtraTrees 多标签分类器，并按独立成分组合分组留出测试集：

- 训练集：603 条
- 测试集：148 条
- 只使用成分：微平均 F1 = 0.7720
- 成分 + 热处理工艺：微平均 F1 = 0.8778

这些指标只描述当前数据集和当前划分下的基线，不代表所有 LAS 微晶玻璃的通用精度。

## 竞赛真实性说明

当前系统使用真实晶相数据，但部分工艺字段为 0，具体含义仍需向数据提供者确认。模型预测、目标晶相候选和特征重要性只能用于科研筛选，不能替代 XRD 鉴定、制样、热处理和实验验证。
